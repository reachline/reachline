# Security

## Supported versions

Only the latest release gets fixes. A security fix is released as soon as it's on `main`, without waiting for the monthly release.

## Reporting a vulnerability

Report it privately, through [GitHub's vulnerability reporting](https://github.com/reachline/reachline/security/advisories/new), and not in a public issue. Include what you found, how to reproduce it, and what someone could do with it. Once it's fixed and released, it's published as an advisory that names the version with the fix, crediting you if you'd like.
